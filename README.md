# Athar Teacher App — Easy Deploy Base 2.0

قالب React + Vite نظيف وخفيف لبناء تطبيق تعليمي، مع فصل الهوية والمنهج ومحتوى الدروس عن الواجهة.

## تشغيل محلي

```bash
npm install
npm run dev
```

## بناء للنشر

```bash
npm run build
```

لا توجد اختبارات أو فحوص إضافية داخل أمر `build` حتى لا تتسبب في تعطيل النشر التلقائي.

ابدأ من `00_ابدأ_من_هنا.md`.
